# Estratégia de desenvolvimento paralelo

Conforme orientação do usuário, BLE MIDI deixa de ser bloqueador obrigatório do primeiro lançamento. Desenvolver em paralelo: A) base FMini-1 compilável, preservação funcional, Neon Collection, Performance Pads Drum/FX, interface aprovada, bateria e Neon Wave, testes e site sincronizado; B) investigação BLE bidirecional usando Custom V022 como referência, sem aplicar patches binários cegamente. Priorizar baseline reproduzível e recuperação segura, necessários em ambas as frentes. Se BLE estiver validado a tempo, incluir na primeira versão; caso contrário, lançar somente após validação dos demais recursos, explicitando ausência de BLE, e manter integração BLE em ramo separado para atualização posterior. Numeração 1.0/1.1 apenas proposta. Não publicar binários não validados. Não substituir presets originais sem aprovação. Registrar evidências de testes e limitações.
