# Regra permanente: firmware e site sincronizados

Aprovada pelo usuário. O firmware Mini Lead é a referência principal para layout, cores, fontes, símbolos, knobs, menus, navegação, parâmetros, animações, timbres e funcionalidades. Toda alteração aprovada deve refletir no site de apresentação, Neon Studio, manual e biblioteca sonora. Representar as telas do firmware de forma idêntica, preservando proporções, desenho e nomenclatura; permitir apenas escala responsiva e elementos externos de navegação web. Usar o design definitivo aprovado, não protótipos anteriores. Recomenda-se compartilhar especificações e dados versionados de interface e presets entre firmware e web, com verificações de correspondência antes de publicar cada versão. Distinguir recursos planejados, simulados e efetivamente disponíveis; não anunciar paridade funcional sem validação. Quando limitações do navegador impedirem reprodução funcional, informar explicitamente sem alterar a representação visual. Atualizar documentação e demonstrações junto de cada release. Preservar funcionalidades e créditos FMini-1. Esta regra é obrigatória para futuras alterações; implementação e validação de paridade ainda pendentes.
